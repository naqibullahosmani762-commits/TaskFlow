# TaskFlow — React Task Manager

A responsive task manager built with React and Vite.

## Run locally
1. Extract the ZIP and open the `taskflow-react` folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown by Vite (usually http://localhost:5173).

## Production build
Run `npm run build`, then `npm run preview`.

## Features
- Create, edit, complete, and delete tasks
- Search tasks by title, description, and category
- Filter by All, Today, Upcoming, and Completed
- Filter by Work, Learning, and Personal
- Priority levels and due dates
- Live summary cards and completion percentage
- Responsive sidebar and mobile layout
- Automatic browser `localStorage` persistence

Tasks are saved in the current browser on this device. There is no remote database or cross-device sync. The initial tasks are sample tasks for demonstrating the app and can be edited or deleted.
